# AGENTS.md — FRC 6940 2026 Rebuilt Offseason

## Project Overview

FRC robot code for Team 6940. 2026 season "Rebuilt" (offseason). Based on the Mechanical-Advantage (FRC 6328) AdvantageKit template. Swerve drivetrain with hybrid auto-aim shooting.

**Stack:** Java 17 · Gradle 8.11 · GradleRIO 2026.2.1 · Phoenix 6 (v26.3.0) · AdvantageKit 26.0.2 · PathPlannerLib 2026.1.2 · Maple-Sim 0.4.0-beta

## Build & Deploy Commands

```bash
./gradlew build              # Compile + package (run before deploy)
./gradlew deploy             # Deploy to roboRIO (team 6940)
./gradlew simulateJava       # Run desktop simulation (physics sim via maple-sim)
./gradlew test               # JUnit 5 tests (currently empty — add tests here)
```

Desktop simulation requires `includeDesktopSupport = true` in `build.gradle` (already enabled).

## Architecture

Entry point chain:

```
Main.java → Robot.java (LoggedRobot) → RobotContainer.java → SuperStructure.java (singleton)
```

**Key files an agent must know:**

| File | Role |
|---|---|
| `src/main/java/frc/robot/Constants.java` | All robot constants, field geometry, motor IDs, PID gains, interpolation tables |
| `src/main/java/frc/robot/RobotContainer.java` | Subsystem wiring, button bindings, auto builder setup |
| `src/main/java/frc/robot/subsystems/SuperStructure.java` | Central coordinator — mode enums (DriveMode, ControlMode, ShootPhase, IntakeMode), command getters |
| `src/main/java/frc/robot/generated/TunerConstants.java` | Auto-generated by CTRE Tuner X swerve project generator |
| `src/main/java/frc/robot/BuildConstants.java` | Auto-generated at build time (git SHA, date, dirty flag) |

**Subsystem packages:** `subsystems/Chassis/`, `subsystems/Shooter/`, `subsystems/Hood/`, `subsystems/Indexer/`, `subsystems/Intake/`, `subsystems/Vision/`, `subsystems/leds/`

**Command packages:** `commands/` (hybrid scoring, intake, drive commands), `commands/Autos/`, `commands/leds/`

**Autonomous system:** `autos/` contains `AutoBuilder.java` (dynamic per-step path chooser on SmartDashboard) and `AutoSegment.java`. Specific auto routines live in `commands/Autos/`. `reference/autos/` has reference implementations (not compiled into the robot).

**IO abstraction pattern:** Each subsystem has an `*IO` interface and two implementations:
- `*IOPhoenix6.java` — real hardware (CTRE Phoenix 6)
- `*IOSim.java` — maple-sim physics simulation

## Do Not Edit

- `src/main/java/frc/robot/BuildConstants.java` — regenerated every build
- `src/main/java/frc/robot/generated/TunerConstants.java` — regenerated by CTRE Tuner X
- `vendordeps/*.json` — managed by vendor tooling; edit via Vendor Dashboard or manually only with care

## Constants & Mode Switching

Simulation vs real is controlled by `Constants.simMode` (line 42 of Constants.java). Currently set to `Mode.SIM`. Change to `Mode.REAL` before deploying to the robot. `currentMode` is derived from `RobotBase.isReal()` at runtime.

NT telemetry publishing is controlled by `Constants.enableNtTelemetry` — set `false` during competition if only USB wpilog is needed.

## Control Flow

Button bindings in `RobotContainer.configureButtonBindings()` define the full driver/operator interface. Priority system for drive modes (highest wins): **AutoAim (Score/Pass/Manual) > HybridTrench > HybridIntake > Manual**.

Shoot phases: `OFF → HEATUP → AIM → READY → SHOOT`. Control modes: `SCORE`, `PASS`, `MANUAL`. Intake modes: `INTAKE`, `HYBRID`, `RETRACTED`, `OFF`, `REVERSE`, `MID`.

## Testing

Tests go in `src/test/java/frc/robot/`. JUnit 5 with auto-detection enabled. Currently no tests exist. The build uses `useJUnitPlatform()` with `junit.jupiter.extensions.autodetection.enabled`.

## Gotchas

- **Subsystem singletons:** CommandSwerveDrivetrain, Intake, Hood, Indexer, Shooter, LEDs, and SuperStructure all use `getInstance()` — don't create duplicate instances.
- **Vendor deps:** JSON files in `vendordeps/` are NOT Gradle dependencies — they're consumed by GradleRIO to pull Maven artifacts. Don't put `implementation` lines for vendor libs in `build.gradle`.
- **Phoenix 6 swerve:** `Robot.java` constructor validates that all modules use `TalonFX_Integrated` for both drive and steer motors. Using other motor types will throw at startup.
- **Field layout:** AprilTag positions are loaded from `src/main/deploy/pathplanner/field2026/2026-official-andymark.json` — not the default WPILib layout. Don't replace with standard `2026-field.json`.
- **PathPlanner warmup:** `FollowPathCommand.warmupCommand()` and `drive.warmupHybridTrenchControlLoop()` are scheduled at robot container init — they must complete before autos work.
