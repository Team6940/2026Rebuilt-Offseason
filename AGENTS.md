# AGENTS.md

## Project Overview

FRC 2026 Rebuilt robot code — Java 17, WPILib (GradleRIO 2026.2.1), AdvantageKit logging, Phoenix 6 (CTRE) swerve drivetrain. Season 2026 game: REBUILT.

## Quick Commands

```bash
# Build (roboRIO target)
./gradlew build

# Deploy to robot
./gradlew deploy

# Run desktop simulation (GUI + driver station)
./gradlew simRun

# Run tests only
./gradlew test

# Clean build artifacts
./gradlew clean
```

## Branch Workflow

All collaborators create their own branches. Changes go to `master` via Pull Request only — never push directly to master.

## Architecture

**Entry point:** `Main.java` → `Robot.java` (extends `LoggedRobot` from AdvantageKit)

**Key files:**
- `src/main/java/frc/robot/Robot.java` — mode dispatch (real/sim/replay), AdvantageKit setup
- `src/main/java/frc/robot/RobotContainer.java` — subsystem instantiation, button bindings, autonomous chooser
- `src/main/java/frc/robot/Constants.java` — all tuning constants, field geometry, motor IDs, projectile lookup tables
- `src/main/java/frc/robot/subsystems/SuperStructure.java` — central state machine (DriveMode, ControlMode, ShootPhase, IntakeMode) and command factory
- `src/main/java/frc/robot/generated/TunerConstants.java` — **auto-generated** by Phoenix 6 Tuner; do not edit manually

**Subsystems (all under `src/main/java/frc/robot/subsystems/`):**
- `Chassis/CommandSwerveDrivetrain` — TalonFX Integrated swerve drive
- `Intake/IntakeSubsystem` — rack + roller, Phoenix 6 motion magic for rack
- `Shooter/ShooterSubsystem` — dual leader/follower pairs (A + B)
- `Hood/HoodSubsystem` — single motor, motion magic position control
- `Indexer/IndexerSubsystem` — feeder + indexer rollers
- `Vision/VisionSubsystem` — fuses Limelight (MegaTag2) + PhotonVision pose estimation
- `leds/LEDController` — single LED strip, state-driven patterns

**IO abstraction pattern:** Each subsystem has an `*IO` interface and two implementations:
- `*IOPhoenix6.java` — real hardware (CTRE Phoenix 6)
- `*IOSim.java` — maple-sim physics simulation

## Simulation

- `Constants.simMode` defaults to `Mode.SIM` — change to `Mode.REPLAY` for log replay
- `Constants.enableNtTelemetry` — set `false` during competition to avoid NT4 publish latency
- Field simulation uses `maple-sim` + custom `FieldSimulation.java` (intake, hopper, dumper shooter)
- AdvantageScope `.json` configs at project root (`AdvantageScope Swerve Calibration.json`)

## Vendor Libraries

All defined in `vendordeps/`:
- **AdvantageKit** (26.0.2) — logging, replay, autolog annotation processor
- **Phoenix 6** (26.3.0) — TalonFX motor controllers, Pigeon IMU
- **PathPlannerLib** (2026.1.2) — autonomous path following
- **PhotonLib** — AprilTag pose estimation
- **ChoreoLib** (2026) — choreography
- **Maple-sim** — physics simulation framework
- **Studica**, **URCL**, **libgrapplefrc2026** — additional vendor libs

## Testing

JUnit 5 with autodetection enabled. Tests live in `src/test/java/frc/robot/`. Run with `./gradlew test`. Desktop simulation support is enabled (`includeDesktopSupport = true` in build.gradle), so IO sim classes allow command-level testing without hardware.

## Common Pitfalls

- **Do not edit `TunerConstants.java`** — it's generated by Phoenix 6 Tuner tool
- **AdvantageKit log files** are written to USB on real robot, `logs/` directory locally (gitignored)
- **CTRE Sim configs** stored in `ctre_sim/` (gitignored)
- **Gradle wrapper** requires Java 17+ on your machine (`JAVA_HOME` must be set)
- **AprilTag field layout** loaded from `src/main/deploy/pathplanner/field2026/2026-official-andymark.json` — must match actual field
